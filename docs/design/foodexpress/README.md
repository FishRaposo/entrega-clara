# FoodExpress wireframe

Origin: the college requirements exercise that seeded this repository, copied from the `College-Projects` repo's `portfolio-food-delivery/` directory.

FoodExpress is the original medium-fidelity wireframe for the food-delivery requirements document in [`docs/requirements/`](../../requirements/). It is a self-contained static page (`index.html` + `styles.css` + `script.js`, pt-BR); open `index.html` in a browser to view it.

This is a historical design artifact, not a current product surface. Product behavior is governed by the [seed design](../../superpowers/specs/2026-08-29-food-delivery-platform-seed-design.md) and the [M1 core delivery-loop design](../../superpowers/specs/2026-09-01-milestone-1-core-delivery-loop-design.md); implementation lives under `app/`.

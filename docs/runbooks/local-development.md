# Local development

This repository is a staged runtime for a deterministic portfolio demo. It is not a production deployment and must not be configured with real payment, GPS, map, or notification credentials.

## Prerequisites

- Python 3.11 or newer
- Node 24.15 or newer

Nothing else is required to install, run, demo, or test the project in the default memory mode: no Docker, WSL, database, `make`, or provider accounts. Optional infrastructure (PostgreSQL persistence, MapTiler tiles) is documented with its prerequisites; see [external dependencies](../architecture/external-dependencies.md).

## Install

From the repository root:

```bash
python -m pip install -e "app/backend[dev]"
cd app/web && npm install
```

Copy `.env.example` to `.env` only if you want to adjust local values; the defaults are safe and require no credentials.

## Run

Start the API from the repository root:

```bash
uvicorn delivery_platform.api.main:app --port 8000
```

Start the web shell in a second terminal:

```bash
cd app/web && npm run dev
```

The API is available at `http://localhost:8000`, including `GET /api/v1/health`; the web shell is available at `http://localhost:3000`. Browser requests use same-origin `/api/...` paths, and Next.js rewrites forward them to `http://localhost:8000` (override with `API_INTERNAL_BASE_URL`).

## Quality gate

The Makefile wraps these commands for environments that have `make`; the plain commands below are the contract and run anywhere:

```bash
python scripts/data/validate_seed.py data/scenarios/lunch-rush.json
python scripts/quality/check_requirement_coverage.py docs/requirements/traceability.md
python scripts/repo/check_app_boundary.py
python -m pytest tests -q
ruff check app/backend/src tests
mypy app/backend/src
cd app/web && npm run lint && npm run typecheck && npm test -- --run && npm run build
```

The browser suite is dev-only tooling:

```bash
cd app/web
npx playwright install        # one-time browser download (or rely on a system Edge/Chrome channel locally)
npm run test:e2e              # boots the API + web servers itself
```

The repository smoke test can run before any application tooling exists:

```bash
python -m pytest tests/repo/test_repository_layout.py -q
```

`python scripts/check.py` is the cross-platform equivalent of `make check` (stdlib only, works in
PowerShell): it runs seed validation, requirement coverage, the app boundary, ruff, mypy, pytest,
web vitest, lint and typecheck in order and prints a pass/fail summary.

## Routing graph and measured evidence

The product and the algorithm lab read `data/graph/sao-paulo-centro-osm.json`, a committed
OpenStreetMap extract (© OpenStreetMap contributors, ODbL 1.0, filtered to the largest strongly
connected component). `data/graph/sao-paulo-centro.json` remains the synthetic fixture for unit tests
and the offline fallback. Override the choice with `ROUTING_GRAPH_PATH` (absolute, or relative to the
repository root); the container falls back to the OSM extract, then the synthetic lattice, then
straight-line routing.

The graph is built offline and never fetched at run time:

```bash
python scripts/data/fetch_osm_graph.py                         # tiled Overpass fetch, cached per area
python scripts/bench/routing_benchmark.py                      # regenerates docs/benchmarks/*
python scripts/bench/routing_benchmark.py --smoke              # ~1 s gate, also run by CI
python scripts/bench/routing_benchmark.py --export-lab-trace   # replay input for the GIF
python scripts/media/render_search_gif.py                      # docs/media/lab-alt-vs-dijkstra.gif
```

Screenshots are generated by the browser suite and written into `docs/media/`:

```bash
cd app/web && npx playwright test --grep @screens
```

`npx playwright test` includes that spec, so a UI change refreshes the committed captures; review the
image diff before committing. Regenerate the benchmark artifacts whenever the graph changes.

## Optional tooling

- **GNU make**: convenience aliases only; each target maps to the plain commands above.
- **Playwright**: dev-only e2e tooling; `npx playwright install` downloads a browser once, and the config can also drive an installed Edge/Chrome channel. Not needed to run the app.
- **MapTiler**: an optional, browser-visible key upgrades the map surface from its deterministic SVG fallback to real tiles once a MapLibre adapter ships. See [M1 runbook §9](milestone-1-development.md); never put a service token in the web bundle.
- **Docker Compose** (`docker-compose.yml`, `Dockerfile`, `app/web/Dockerfile`): an optional container path defining `db`, `api`, `worker` and `web` services. It is not required to run or test the project; it exercises the implemented PostgreSQL adapter (`PERSISTENCE_MODE=postgres`) and is the basis of the deploy artifacts. See the [PostgreSQL runbook](postgres.md).

## Non-production boundary

Payments are simulated, GPS movement is simulated, map data may be seeded or generalized, and notifications have no provider credentials. Role navigation is a demo aid, not authentication or identity verification. This project does not claim payment certification, production compliance, real courier operations, or measured uptime.
